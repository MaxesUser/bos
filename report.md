# Лабораторная работа №1

## 2.1. Перемещение по файловой системе

### 2.1.1 Авторизуйтесь в системе в текстовом режиме, либо в графическом режиме. Если вы работаете в графическом режиме, запустите программу эмулятора терминала.

### 2.1.2 Выведите имя текущего пользователя, установите, в каком каталоге вы сейчас находитесь.
```bash
whoami
pwd
```

### 2.1.3 Перейдите в корневой каталог. Попробуйте перейти в каталог уровня выше.
```bash
cd /
cd ..
```

### 2.1.4 Выведите список файлов текущего каталога.
```bash
ls
```

### 2.1.5 Выведите список файлов каталога /etc.
```bash
ls -la /etc
```

### 2.1.6 Перейдите в домашний каталог текущего пользователя.
```bash
cd
```

### 2.1.7 Выведите список файлов и каталогов текущего каталога.
```bash
ls
```

### 2.1.8 Выведите список файлов и каталогов (включая скрытые) с информацией о владельце и правах доступа.
```bash
ls -la
```

## 2.2. Работа с файловой системой

### 2.2.1 В домашнем каталоге текущего пользователя создайте подкаталог fruits.
```bash
mkdir fruits
```

### 2.2.2 Перейдите в корневой каталог. Из корневого каталога создайте в домашнем каталоге подкаталог animals.
```bash
cd /
mkdir /home/kali/animals
```

### 2.2.3 В подкаталоге корневого каталога, предназначенного для хранения временных файлов, создайте пустой файл temp.
```bash
mkdir /tmp/temp
rm -r /tmp/temp
touch /tmp/temp
```

### 2.2.4 Используя команду echo и перенаправление вывода запишите в файл temp строку «Hello». Второй такой командой допишите строку «world». Откройте файл при помощи текстового редактора nano, добавьте в конец три знака «!», сохраните запись и выполните выход из редактора.
```bash
echo "Hello" > /tmp/temp
echo "world" >> /tmp/temp
nano /tmp/temp
```

### 2.2.5 Перейдите в каталог fruits и создайте в нем пустые файлы apple, banana, pineapple, lion (используйте соединение команд при помощи &&).
```bash
cd /home/kali/fruits
touch apple && touch banana && touch pineapple && touch lion
```

### 2.2.6 Находясь в каталоге fruits, создайте в каталоге animals пустые файлы cat.txt, dog.txt, elephant.txt одной командой.
```bash
touch ~/animals/cat.txt ~/animals/dog.txt ~/animals/elephant.txt
```

### 2.2.7 Выведите все файлы каталога fruits, имя которых начинается с буквы a.
```bash
ls a*
```

### 2.2.8 Выведите все файлы каталога fruits, имя которых заканчивается буквой e.
```bash
ls *e
```

### 2.2.9 Выведите все файлы каталога fruits, имя которых содержит буквы a и n.
```bash
ls *a*n*
ls | grep "a" | grep "n"
```

### 2.2.10 Скопируйте файл с учетными записями пользователей системы в домашний каталог текущего пользователя. Выведите на экран количество строк в этом файле. В домашнем каталоге создайте символьную ссылку на этот файл. Определите номер inode этой ссылки.
```bash
cp /etc/passwd ~/passwd
wc -l ~/passwd
ln -s ~/passwd ~/passwd_l
ls -i ~/passwd_l
```

### 2.2.11 Выведите содержимое файла /etc/issue на экран.
```bash
cat /etc/issue
```

### 2.2.12 Скопируйте файл /etc/issue в файл apple с заменой содержимого, выполните проверку.
```bash
cp /etc/issue ~/fruits/apple
cat ~/fruits/apple
```

### 2.2.13 Переместите файл lion в каталог animals.
```bash
mv ~/fruits/lion ~/animals
```

### 2.2.14 Исправьте опечатку в имени файла pineapple.
```bash
mv ~/fruits/pineapppple ~/fruits/pineapple
ls ~/fruits
```

### 2.2.15 В домашнем каталоге создайте жесткую ссылку на файл истории команд командной оболочки. Выведите информацию о количестве жестких ссылок на этот файл.
```bash
ln ~/.bash_history ~/bash_history_hl
fc -W
ls -l ~/bash_history_hl
ls -i ~/bash_history_hl
```

### 2.2.16 Удалите каталог fruits.
```bash
rm -r ~/fruits
```

### 2.2.17 Выведите на экран содержимое файла лога загрузки операционной системы.
```bash
cat /var/log/boot.log
sudo cat /var/log/boot.log
```

## 2.3. Механизм конвейеров

### 2.3.1 Выведите на экран отсортированный по алфавиту список пользователей операционной системы.
```bash
cat /etc/passwd | sort
```

### 2.3.2 Выведите на экран число пользователей, у которых командной оболочкой является bash.
```bash
grep -c '/bash$' /etc/passwd
```

### 2.3.3 Выведите на экран только имена пользователей, использующих командную оболочку bash, отсортировав их по алфавиту в обратном порядке.
```bash
grep '/bash$' /etc/passwd | cut -d: -f1 | sort -r
```

### 2.3.4 Выведите на экран имена пользователей и используемую ими командную оболочку (в две колонки).
```bash
cut -d: -f1,7 /etc/passwd | column -t -s:
```

## 2.4. Получение прав суперпользователя

### 2.4.1 Выведите на экран содержимое файла с паролями пользователей, выполняя команду от имени текущего пользователя.
```bash
cat /etc/shadow
```

### 2.4.2 Выведите список групп текущего пользователя на экран. Установите, входит ли ваш пользователь в группу администраторов? Если нет, завершите сеанс текущего пользователя и авторизуйтесь как root. Включите пользователя в группу администраторов командой usermod.
```bash
groups
id
sudo usermod -aG sudo $USER
```

### 2.4.3 От имени суперпользователя (sudo <>) выполните команду из п. 2.4.1.
```bash
sudo cat /etc/shadow
```

### 2.4.4 Выведите список всех пользователей, входящих в группу администраторов.
```bash
getent group sudo
grep '^sudo' /etc/group
```

### 2.4.5 Обновите список доступных для установки пакетов, выполните установку пакета build-essential. Проверьте версии установленных компиляторов и средств автоматизации сборки.
```bash
sudo apt update
sudo apt install -y build-essential
gcc --version
make --version
cmake --version
```

## 2.5. Поиск файлов и каталогов

### 2.5.1 Изучите доступные опции утилиты find.
```bash
man find
```

### 2.5.2 Найдите все файлы и каталоги, имя которых содержит подстроку pass с учётом регистра.
```bash
find / -name '*pass*' 2>/dev/null
```

### 2.5.3 Найдите все файлы и каталоги, имя которых содержит подстроку pass без учёта регистра.
```bash
find / -iname '*pass*' 2>/dev/null
```

### 2.5.4 Найдите все файлы и каталоги, имя которых содержит подстроку pass с учётом регистра. Начните поиск с / и ограничьте глубину одним уровнем.
```bash
find / -maxdepth 1 -name '*pass*' 2>/dev/null
```

### 2.5.5 Найдите все файлы и каталоги, имена которых оканчиваются на .bin. Выполните поиск в каталоге /home и всех его подкаталогах.
```bash
find /home -name '*.bin' 2>/dev/null
```

### 2.5.6 Найдите все обычные файлы и только их, имена которых оканчиваются на .bak, и удалите их.
```bash
find . -type f -name '*.bak' -delete
```

### 2.5.7 Найдите все обычные файлы и только их, имена которых оканчиваются на .txt или .sh.
```bash
find . -type f \( -name '*.txt' -o -name '*.sh' \)
```

### 2.5.8 Найдите все обычные файлы и только их в текущем каталоге и всех его подкаталогах. Для каждого файла выведите только следующие сведения: имя файла без пути, имя владельца, имя группы владельца, количество жёстких ссылок и размер в байтах.
```bash
find . -type f -printf '%f %u %g %n %s\n'
```

### 2.5.9 Найдите все пустые каталоги внутри текущего каталога, включая вложенные. Сам текущий каталог в результат не включайте.
```bash
find . -mindepth 1 -type d -empty
```

### 2.5.10 Найдите и удалите все пустые каталоги внутри текущего каталога, включая вложенные. Сам текущий каталог сохраните.
```bash
find . -mindepth 1 -type d -empty -delete
```

### 2.5.11 Найдите и удалите все пустые обычные файлы и только их. Пустым считайте файл размером 0 байт.
```bash
find . -type f -empty -delete
```

### 2.5.12 Найдите все обычные файлы и только их в текущем каталоге и всех его подкаталогах, у которых количество жёстких ссылок больше одной.
```bash
find . -type f -links +1
```

### 2.5.13 Найдите все файлы и каталоги в /etc и его подкаталогах, не принадлежащие пользователю root.
```bash
find /etc ! -user root 2>/dev/null
```

### 2.5.14 Найдите все обычные файлы и только их, имена которых не оканчиваются на .sh. Файлы без расширения также должны попадать в результат.
```bash
find . -type f ! -name '*.sh'
```

### 2.5.15 Найдите все обычные файлы и только их, у которых количество жёстких ссылок больше двух.
```bash
find . -type f -links +2
```

### 2.5.16 Найдите все обычные файлы и только их в /usr/bin и его подкаталогах, сохранённая метка последнего доступа к которым (atime) указывает на время более 90 суток назад.
```bash
find /usr/bin -type f -atime +90
```

### 2.5.17 Найдите все обычные файлы и только их в каталогах /usr/bin и /usr/share, включая их подкаталоги, содержимое которых изменялось в течение последних 10 суток. Используйте время изменения содержимого (mtime).
```bash
find /usr/bin /usr/share -type f -mtime -10
```

### 2.5.18 Найдите и удалите все обычные файлы и только их в /tmp и его подкаталогах, последнее изменение содержимого которых произошло более 14 суток назад. Используйте время изменения содержимого (mtime).
```bash
find /tmp -type f -mtime +14 -delete
```
